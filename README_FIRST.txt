TENDERGUARD AI - START HERE

1. Extract the ZIP file.
2. Open the extracted TenderGuard-Prototype folder.
3. Double-click install_tenderguard.bat and wait for completion.
4. Double-click run_tenderguard.bat.
5. Keep the black terminal window open while using the webpage.
6. Leave "Built-in demo" selected and click "Analyse tender documents".

The core checker works without an API key. AI validation is optional and
switched off by default.

For detailed instructions, open README.md in VS Code or a text editor.
